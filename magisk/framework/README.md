# BelleUI - Android framework colours

A static runtime resource overlay (`framework-overlay`) on the `android` package, built from the colours of the
Symbian Belle firmware: black pages, white text, `#999999` secondary text, the `#1080DD` list-pressed blue as the accent,
`#0072B2` text selection, `#1B1B1B` popup plates, 15 % white dividers, and the light (inverse) theme `#F1F1F1` / `#282828`.
It is signed with the AOSP platform key, as the ROM is, so the system accepts it for the framework.
The framework APK itself is not touched.
