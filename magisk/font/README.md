# BelleUI - Nokia Sans system font

Nokia Sans S60 Regular (`nosnr60.ttf`) and SemiBold (`nssb60.ttf`) come from the firmware dump and are the faces the Belle UI
is set in. Thin, Light and Regular become Regular; Medium, Bold and Black become SemiBold. Characters Nokia Sans does not
have (emoji, CJK, ...) still come from the system's other fonts. The fonts are Nokia's: keep the repository private.
