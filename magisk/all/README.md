# BelleUI - the whole set (Magisk module)

Installs the Belle launcher and all the Belle apps as system apps (systemless), then at each boot grants them
the access they need (file access, system settings, usage access, notification access, calendar, microphone)
and, if you want, makes the Belle launcher the home app.

Edit `/data/adb/belleui/config` to turn the defaults on or off.
